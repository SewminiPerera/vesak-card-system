> A beautiful bilingual digital Vesak greeting card creator built with pure HTML, CSS & JavaScript.

**Live Demo:** https://sewminiperera.github.io/vesak-card-system/

## ✨ Features

- 🌐 **Bilingual** — Full Sinhala & English support
- 🎨 **10 Unique Templates** — AI-generated & gradient art backgrounds
- 📝 **10 Original Poems** — About Lord Buddha in both languages
- 👤 **Personalization** — Add sender & recipient names
- 📥 **High-Quality Download** — Export as PNG (1350×900px / 9"×6")
- 📱 **Fully Responsive** — Works on all devices
- ✨ **Premium Design** — Gold & purple Buddhist theme

## 🚀 Getting Started

Simply open `index.html` in any modern browser — no build step required!

```bash
git clone https://github.com/SewminiPerera/vesak-card-system.git
cd vesak-card-system
# Open index.html in your browser
```

---

## 🛠 Tech Stack

- **HTML5** — Semantic structure
- **Vanilla CSS** — Premium animations & glassmorphism
- **Vanilla JavaScript** — App logic
- **html2canvas** (CDN) — Card download
- **Google Fonts** — Noto Sans Sinhala, Cinzel, Cormorant Garamond

---

## 📐 Card Dimensions

- **Size:** 9" × 6" (1350 × 900px at 150 DPI)
- **Layout:** Left half = photo template | Right half = poem + names + wishes
